OVERVIEW

This project is a Unity-based VR network visualization system designed to transform real network traffic data into an interactive 3D graph.

The system renders:

MAC nodes (devices)
IP nodes (addresses)
Connections (network traffic)

Users can explore the network in VR, inspect nodes, and filter traffic in real time.

SYSTEM ARCHITECTURE

The system is organized into five layers:

DATA LAYER
VisIface
Handles database communication
Converts raw data into structured models (Node, SubConnection)
Keeps data logic separate from Unity scene logic
SCENE CONSTRUCTION LAYER
NodeSpawnerScript
Core orchestrator of the visualization
Builds the graph in multiple stages:
MAC node creation
Subnet-based layout
MAC-to-MAC connections
IP layer generation
MAC-to-IP edges
Applies layout relaxation to reduce overlap
INTERACTION LAYER
ShowNodeInfo
Handles XR-based object selection
Sends selected object data to the UI

RayTargetModeToggle

Controls interaction modes:
Nodes only
Connections only
Both
UI only
FILTERING LAYER
FilterSystem
Controls visibility rules
Filters based on:
Protocol
MAC/IP connections
IPv6 noise
Noisy MACs

FilterButtonVisual

UI buttons for toggling filters
Sends commands to FilterSystem
UI LAYER
InfoPanelController
Displays selected data
Formats node/connection information

AutoScrollTMP

Scrolls long text fields (IPs, ports, protocols)

Panel Scripts

Control UI placement and visibility in VR
RUNTIME FLOW

STARTUP SEQUENCE

Initialize data source (VisIface)
Fetch nodes and connections
Generate MAC nodes
Layout MAC subnet rings
Create MAC-to-MAC edges
Generate IP layer
Create MAC-to-IP edges
Apply default filters

LIVE UPDATE LOOP

Poll for new traffic
Spawn new nodes if needed
Add new connections
Update node alerts/warnings
Reapply filters

USER INTERACTION FLOW

User selects object with XR ray
ShowNodeInfo identifies object type
InfoPanelController updates UI
AutoScrollTMP scrolls long content
DATA MODEL

VR ray interaction system
